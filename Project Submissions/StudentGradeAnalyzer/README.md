\# Student Grade Analyzer



\## Project Overview



The Student Grade Analyzer is a Python program that reads student grade data from a CSV file and analyzes the results. The program assigns letter grades, calculates summary statistics, creates a new results file, and generates a visualization.



\## Problem



Manually reviewing and summarizing student grades can be repetitive. This project automates that process.



\## Features



\- Reads student names and scores from a CSV file

\- Assigns letter grades

\- Calculates the class average

\- Identifies the highest score

\- Identifies the lowest score

\- Creates a processed CSV file

\- Creates a PNG bar chart



\## Files



\- grade\_analyzer.py - main Python program

\- student\_grades.csv - original input data

\- grade\_results.csv - processed grade data

\- grade\_distribution.png - visualization

\- README.md - project documentation



\## Requirements



Python 3



matplotlib



Install matplotlib with:



pip install matplotlib



\## How to Run



Open Anaconda PowerShell Prompt.



Navigate to the project folder.



Run:



python grade\_analyzer.py



The program will display the summary statistics and create the output CSV and PNG files.



\## Grade Scale



A = 90-100



B = 80-89



C = 70-79



D = 60-69



F = below 60
